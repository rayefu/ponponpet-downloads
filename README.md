# PonPonPet 列印助手

PonPonPet 的官方電腦列印助手下載區。此處只提供已發布的安裝檔及檔案校驗資訊，不公開 PonPonPet 完整專案儲存庫，不包含店家資料或憑證。安裝檔含助手執行所需的程式。

使用方式：安裝並開啟助手，在 PonPonPet 的「店家設定 → 設備與列印」完成配對，再指定系統已安裝的印表機。

- Mac：依晶片選擇 Apple Silicon 或 Intel 安裝檔；需要 macOS 13 或以上。安裝檔經 Developer ID 簽章與 Apple 公證。
- 固定使用的櫃台可在配對時勾選「記住這台受信任櫃台」，並於助手確認。
- 關閉助手視窗後仍在選單列執行；需要結束時，請在助手內選擇「結束列印助手」。
- 每份列印文件仍須在本機預覽並確認。助手不會另開發票；發票沿用已開立文件。
- 實際紙張、切紙與輸出格式依印表機及其驅動程式而定，請先測試。
- Windows Store 版本尚待審查，本區不提供未簽署 Windows 安裝檔。

官方網站：[PonPonPet](https://www.ponponpet.com/)
